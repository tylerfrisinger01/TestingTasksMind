# AI Software Engineer Agent

An autonomous AI agent that processes software development tickets, generates code, runs tests, and creates pull requests.

## Features

- **Webhook Integration**: Automatically detects when tickets are assigned
- **AI Analysis**: Uses Claude 3.5 Sonnet to analyze tickets and requirements
- **Task Breakdown**: Intelligently breaks down complex tickets into subtasks
- **Code Generation**: Autonomously generates production-ready code
- **Test Execution**: Runs tests to validate generated code
- **PR Creation**: Automatically creates pull requests with changes

## Setup

### Prerequisites

- Node.js 18+
- Anthropic API key
